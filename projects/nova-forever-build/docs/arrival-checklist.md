# Incoming parts inspection

For each delivery: record date, actual part number, quantity, vendor, price (if known), photos, condition, connector/pinout, voltage/current ratings, dimensions, test result, and storage location. Mark **received** only after physical confirmation. Photograph labels and retain receipts privately.

## Safety
Do not energize unidentified boards or motors. Check polarity, battery chemistry and protection, supply voltage, wiring gauge, motor stall current and fusing before power-on. Test mechanical locking before powered docking.
