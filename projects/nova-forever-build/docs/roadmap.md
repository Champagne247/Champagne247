# Project roadmap (planning, not a delivery commitment)

**Now:** document existing hardware orders and deliveries, budget, desired robot scale and first prototype requirements.

**Phase 1:** component inventory, bench power tests, controller and motor driver identification.

**Phase 2:** parametric CAD, assembly and universal docking interface draft; printable tolerance tests.

**Phase 3:** safe tracked-base prototype and independent companion motion; basic control firmware.

**Phase 4:** camera eyes, speech, perception and modular software integration.

**Phase 5:** dock detection, locking, power isolation and controlled carrier handoff.

**Later:** BUDDY/PIP variants, arms, HOME station, alternate carriers, possible aerial module subject to extensive safety testing.
