# Procurement and validation checklist

- [ ] Inventory existing motors, batteries, Raspberry Pi, phone, 3D printer access and tools.
- [ ] Decide initial platform: 2-wheel differential drive with caster or compact tracks.
- [ ] Confirm target size, mass, battery runtime and available build volume.
- [ ] Recheck vendor prices, availability and exact SKU revisions.
- [ ] Confirm all power rails, motor stall currents and driver ratings before purchase.
- [ ] Acquire protective fusing, emergency stop, wiring and bench supply before actuators.
- [ ] Bench test compute and expression before drive integration.
- [ ] Publish test evidence, failures and design revisions.
- [ ] Validate unpowered dock geometry before adding power contacts.
- [ ] Never use shared connector with flight platform until independent flight safety review.
