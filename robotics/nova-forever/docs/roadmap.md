# Roadmap and milestone gates

| Phase | Deliverable | Exit criterion |
|---|---|---|
| 0 | Requirements, system diagram, risk register, candidate BOM | Major unknowns and owners documented |
| 1 | Bench electronics and expressive face | Repeatable safe boot, voice/face demo, E-stop test |
| 2 | Printed interface coupons | Measured mating and latch fit |
| 3 | Low-speed mobile MVP | Controlled motion, obstacle stop, supervised operation |
| 4 | Powered HOME dock | Verified interlocks, protected charging, fault tests |
| 5 | Three unique shells/personas | Common interface and differentiated character behavior |
| 6 | Optional carrier modules | Each platform independently validated |

## Immediate next actions
1. Decide whether the first MVP rolls/tracks or walks; recommend tracks/wheels for fast validation.
2. Set target budget, available printer/build volume and desired local-vs-cloud AI.
3. Choose components only after torque, battery, thermal and mass budgets.
4. Produce CAD source files, STL exports and print/test logs; never label illustrations as printable designs.
5. Review safety for pinch points, battery, charging, autonomous motion and any flight hardware.
