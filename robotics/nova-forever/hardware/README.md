## First bench prototype
- Select processor and controller based on local voice/vision needs and actuator interfaces.
- Compare camera, speaker/microphone, display, servos, motor drivers and sensors.
- Create preliminary mass, power, thermal and cost budgets.
- Design simple printed dock alignment coupons before a full character shell.
- Select battery and charging system with appropriate protection; no improvised charging circuits.
- Produce wiring diagrams, fuse/current limits, E-stop and safe-start behavior before motion tests.
